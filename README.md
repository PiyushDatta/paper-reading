# Paper reading

A personal archive of LLM and transformer research PDFs.

Add PDFs directly here or organize them into folders whenever useful. Use clear filenames, such as `2024-short-paper-title-v2.pdf`, so the paper and version are easy to recognize. No index, reading-status system, or notes are required.

When a paper becomes an implementation project, create a separate repository from [llm-paper-template](https://github.com/PiyushDatta/llm-paper-template). Keep that paper's implementation, baseline, ablations, and experimental notes together in the new repository.
